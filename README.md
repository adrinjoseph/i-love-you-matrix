# 💖 Orbiting Love: 3D Kinetic Heart Animation

A mesmerizing, interactive 3D heart animation crafted out of dynamic typography strings that infinitely loop. This project balances precise geometric styling with lightweight frontend engineering to form a perfect digital gift for someone truly special.

## ✨ Features
* **Perfect 3D Architecture:** Constructed using precise CSS mathematical steps and keyframe matrix transformations to prevent shape warping or distortion.
* **Kinetic Text Flow:** The phrases continuously stream, shift, and ripple along a distinct vector path without disrupting the primary heart outline.
* **Ambient Glow:** Uses custom text-shadow lighting effects to simulate a neon-pink ambient luminescence against a deep midnight background canvas.
* **Vanishing Footprint:** Built entirely on vanilla **HTML5, CSS3, and JavaScript** with zero heavy dependencies or external framework packages.

## 📁 File Structure
```text
.
├── index.html     # Structural DOM mount point
├── style.css      # Keyframe coordinates, layout & 3D perspectives
├── script.js     # Component item loop injector & index variable maps
└── README.md      # Documentation and project profile
```

## 🚀 Quick Setup

To run this animation locally on your device:

1. **Clone or Download** this repository.
2. Open **Git Bash** or your terminal inside the folder.
3. Open `index.html` directly in any web browser, or launch it with an extension like **Live Server** inside VS Code for real-time adjustments.
